# SGA-DO — Sistema de Gestión Académica

Sistema de gestión académica desarrollado como proyecto de formación en programación.

El proyecto permite administrar información de alumnos y profesores, gestionar calificaciones, controlar operaciones y organizar certificados mediante diferentes estructuras de datos.

## 📌 Características principales

- Registro y gestión de alumnos.
- Registro y gestión de profesores.
- Administración de calificaciones.
- Deshacer operaciones relacionadas con notas.
- Gestión de una cola de certificados.
- Generación de reportes generales.
- Validación y almacenamiento de información.

## 🛠️ Tecnologías utilizadas

- Python
- Java
- C++ (en desarrollo)

## 🧠 Conceptos aplicados

- Lógica de programación.
- Programación estructurada.
- Programación orientada a objetos (POO).
- Manejo de archivos.
- Validación de datos.
- Estructuras de datos: pilas (Stack) y colas (Queue).

## 📂 Organización del repositorio

- `Phyton/`: implementación en Python.
- `Java/`: implementación en Java.
- `C++/`: implementación en C++.
- `Docs/`: documentación del proyecto.

## 🎯 Objetivo del proyecto

Fortalecer los conocimientos de programación mediante la construcción de un sistema funcional, aplicando diferentes lenguajes, estructuras de datos y técnicas de organización del código.
